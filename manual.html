성경읽기 앱 사용 매뉴얼

매일 정해진 분량의 성경을 읽고, 읽은 기록을 목장 식구들과 나누는 앱입니다. 스마트폰과 PC 어디서나 인터넷 주소로 바로 열 수 있고, 따로 설치하거나 회원가입할 필요가 없습니다.

1. 앱 열기

  • 인터넷 주소: kghwang1.github.io/bible/
  • 또는 아래 QR 코드를 휴대폰 카메라로 비추면 바로 열립니다.

💡 바로가기 만들기 — 크롬에서 앱을 연 뒤 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가를 누르면 휴대폰 바탕화면에 아이콘이 생겨 다음부터 한 번에 열 수 있습니다.

2. 처음 시작할 때 — 설정하기

처음 앱을 열면 홈 화면에 "시작 전에 설정값을 입력하세요" 안내가 나옵니다. 제목 옆 ⚙ (톱니바퀴) 버튼을 눌러 설정 창을 엽니다.

항목 입력 방법
성경 버전 읽을 성경을 고릅니다 — 개역개정, 새번역, 현대인의성경, NIV 영어, KJV 한글, KJV 영어
읽는 방법 읽기표를 고릅니다 (연대순 / 성경순)
시작 날짜 (1일차) 읽기를 시작한 날을 정합니다. 아래에 365일 뒤 종료 예정일이 자동으로 표시됩니다. 처음부터 다시 하려면 초기화를 누릅니다.
목장 · 이름 내 목장 이름과 내 이름을 적습니다. 완료 화면과 공유 이미지에 표시됩니다.
우리 목장 기도제목 목장이 함께 기도할 제목을 적습니다. 목장 이름별로 저장되어 같은 목장 목원들과 공유됩니다.

모두 입력했으면 맨 아래 완료를 누릅니다.

💡 성경 버전은 나중에 언제든 ⚙ 설정에서 바꿀 수 있습니다. 기도제목은 인터넷에 연결되어 있어야 저장됩니다.

설정과 읽기 기록을 기기에 저장하기 · 불러오기

설정 창 아래쪽 💾 기기에 저장 · 불러오기에서 내 설정(성경 버전, 읽는 방법, 시작 날짜, 목장·이름)과 지금까지의 읽기 기록을 파일 하나로 저장하고, 나중에 다시 불러올 수 있습니다. 휴대폰을 바꾸거나, 다른 브라우저로 옮기거나, 인터넷 사용 기록을 지우기 전에 쓰세요.

저장하기

  1. 홈 화면 ⚙ → 설정 창을 엽니다.
  2. 💾 기기에 저장을 누릅니다.
  3. 휴대폰은 다운로드 폴더에 성경읽기_설정_이름_날짜.json 파일이 저장됩니다. PC 크롬에서는 저장할 위치를 직접 고를 수 있습니다.
  4. 다른 휴대폰으로 옮길 때는 이 파일을 카카오톡 나와의 채팅이나 이메일로 보내 두면 편합니다.

불러오기

  1. 설정 창에서 📂 불러오기를 누릅니다.
  2. 저장해 둔 .json 파일을 고릅니다.
  3. "이 파일의 설정과 읽기 기록으로 바꿀까요?"에서 확인을 누르면 앱이 다시 열리면서 저장해 둔 상태로 돌아갑니다.

⚠ 불러오면 지금 기기에 있는 설정과 읽기 기록은 파일 내용으로 바뀝니다. 목장 기도제목은 인터넷에 목장 이름으로 저장되므로 파일과 상관없이 그대로 보입니다.

4. 오늘 말씀 읽기 — 매일읽기

홈에서 매일읽기를 누르면 오늘 읽을 본문이 열립니다.

  • 맨 위: 오늘 날짜와 몇 일째인지(예: 제3일), 오늘 읽을 범위(예: 창세기 6-9장)가 표시됩니다.
  • [새번역] [창세기] [6장] 버튼: 눌러서 성경 버전, 책, 장을 바로 바꿀 수 있습니다.
  • 좌우 화살표 ‹ ›: 화면 양옆 화살표로 이전 장·다음 장으로 넘어갑니다.
  • A+ / A-: 글자 크기를 키우거나 줄입니다.
  • 파란색 단어: 인물·지명·용어입니다. 누르면 뜻풀이(성경 용어 사전)가 나옵니다.
  • 모두읽음: 오늘 분량을 다 읽었으면 오른쪽 위 모두읽음 버튼을 누릅니다.

5. 읽기 완료와 공유하기

모두읽음을 누르면 "축!! 완료" 화면이 나옵니다.

  • 오늘 읽은 범위와 지금까지의 진행률(예: 1일 / 365일 (0%) 읽음)
  • 날짜와 내 이름, 우리 목장 기도제목
  • 아래 버튼: 홈 · 목록으로 · 다음 읽기 → (다음 날 분량을 이어서 읽기)

📤 공유하기를 누르면 완료 화면이 이미지로 만들어지고 휴대폰 공유 창이 열립니다. 카카오톡을 골라 목장 단톡방에 보내면 됩니다.

목장 식구들이 각자 올린 완료 이미지로 서로의 읽기를 격려할 수 있습니다.

6. 읽기 목록 — 진행 상황 보기

홈에서 목록을 누르면 365일 읽기표가 나옵니다.

  • 오른쪽 위: 지금까지 읽은 날 수와 진행 막대(예: 195 / 365)
  • 보기: 전체 / 미읽음 / 완료 중 골라서 볼 수 있습니다. 놓친 날만 보려면 미읽음을 누르세요.
  • 날짜 카드: 날짜, 읽을 범위, 몇 일차인지 표시됩니다. 오늘은 TODAY로 강조됩니다.
  • ✓ 읽음: 읽은 날에 표시됩니다. 오른쪽 표시를 눌러 읽음/안읽음을 바꿀 수 있습니다.
  • 아무 날이나 누르면 그날 본문이 열리므로, 밀린 분량도 목록에서 골라 읽으면 됩니다.

7. 성경책 — 원하는 곳 찾아 읽기

홈에서 성경책을 누르면 읽기표와 상관없이 원하는 곳을 펼칠 수 있습니다.

  • 위쪽 탭 버전 / 신약 / 구약 / 장 순서로 고릅니다. 예: 신약 → 요한복음 → 장 선택
  • 위쪽 파란 구절찾기 버튼으로 언제든 다시 책과 장을 고를 수 있습니다.

8. TTS — 성경 듣기

홈의 TTS 버튼을 누르면 성경 본문을 소리로 읽어 줍니다. 운전 중이나 눈이 피곤할 때 유용합니다.

  • ▶ 재생 / 일시정지, ⏮ 이전 절, ⏭ 다음 절
  • 속도 버튼으로 0.8× ~ 2× 사이에서 빠르기를 바꿀 수 있습니다.
  • ✕ 버튼으로 듣기를 끝냅니다.

9. 부록 — 성경 공부 자료

홈에서 부록을 누르면 성경 이해를 돕는 자료가 모여 있습니다.

자료 내용
📖 성경 용어 사전 인물·지명·용어를 검색해 뜻을 찾습니다 (예: 아브라함, 바로, 안식일)
🗺 성경 지도 대한성서공회 제공 지도 — 구약 26장, 신약 9장

10. 자주 묻는 질문

Q. 읽은 기록은 어디에 저장되나요?
지금 쓰고 있는 휴대폰(또는 PC)의 인터넷 브라우저 안에 저장됩니다. 다른 휴대폰이나 다른 브라우저로 열면 기록이 보이지 않으니, 늘 같은 기기·같은 브라우저(예: 크롬)로 여세요. 브라우저의 "인터넷 사용 기록 삭제"로 사이트 데이터를 지우면 기록이 사라질 수 있습니다.

Q. 휴대폰을 바꿨어요. 읽은 기록을 옮길 수 있나요?
예전 휴대폰에서 ⚙ 설정 → 💾 기기에 저장으로 파일을 만들고, 그 파일을 새 휴대폰으로 보낸 뒤 ⚙ 설정 → 📂 불러오기로 열면 됩니다. (2장 '기기에 저장 · 불러오기' 참고)

Q. 성경 버전을 바꾸고 싶어요.
홈 화면 ⚙ 설정에서 바꾸거나, 읽기 화면 위쪽의 버전 버튼을 누르세요.

Q. 기도제목이 저장되지 않아요.
인터넷 연결을 확인한 뒤 다시 완료를 눌러 주세요. 기도제목은 목장 이름으로 저장되므로 목원들이 목장 이름을 똑같이 적어야 같은 기도제목을 함께 봅니다.

Q. 며칠 밀렸어요.
목록 → 미읽음을 누르면 아직 안 읽은 날만 모아 볼 수 있습니다. 하나씩 눌러 읽으면 됩니다.

Q. 처음부터 다시 시작하고 싶어요.
⚙ 설정의 시작 날짜 옆 초기화를 누르고 새 시작 날짜를 정하세요.
